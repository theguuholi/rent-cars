# RentX-inspired web UI

> Historical first iteration. The approved follow-up is recorded in
> [Fluid RentCars UI](2026-11-24-fluid-ui.md); its white navigation, rounded
> surfaces and unified search supersede the initial styling below.

## Approved design

Implement the reviewed mockups in React with Tailwind v4. Use a charcoal header,
red actions, pale gray canvas, white surfaces, Archivo headings and Inter body.
Keep the existing routes, role visibility, API contracts and business validation.
The home remains navigation-only. Shared presentation belongs in components;
feature state and HTTP calls stay with their existing owners.

The catalog API has no image metadata: use an honest neutral vehicle illustration,
not fake vehicle photos or one extra detail request per card. Real uploaded photos
remain in the detail gallery. Car descriptions remain required.
